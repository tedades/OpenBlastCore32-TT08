# OpenBlastCore32-TT08
OpenBlastCore is an open-source 32bit custom ISA chip designed for retro-gaming on the Tiny TapeOut demo board

PMODs used:
Audio: https://store.tinytapeout.com/products/Audio-Pmod-p716541601
VGA: https://store.tinytapeout.com/products/Tiny-VGA-Pmod-p678647356
QSPI (Flash + PSRAM): https://store.tinytapeout.com/products/QSPI-Pmod-p716541602
SNES Controller inputs: https://store.tinytapeout.com/products/Gamepad-Pmod-p741891425
